# Gataria Mockup Studio

1. Extraia todo o ZIP.
2. Dê dois cliques em `INICIAR_APP.bat`.
3. Escolha camiseta preta ou branca.
4. Carregue a estampa e use a remoção de fundo com IA.
5. Ajuste e baixe o mockup em PNG.

A remoção de fundo com IA precisa de internet na primeira execução para carregar o modelo. O processamento acontece no navegador.
